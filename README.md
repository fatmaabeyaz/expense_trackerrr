# 💸 Expense Trackerrr

Kişisel gelir ve giderlerinizi takip edebileceğiniz bir Flutter tabanlı **harcama takip uygulaması**. Uygulama Firebase altyapısı kullanarak verileri saklar ve modern bir kullanıcı arayüzü ile kolay kullanım sunar.

---

## 🚀 Özellikler

- ✅ Gelir ve gider ekleme
- 📋 Harcamaları listeleme
- ☁️ Firebase ile veri saklama
- 🧱 Temiz ve bileşen bazlı Flutter mimarisi
- 📦 Kolay ölçeklenebilir proje yapısı

---

## 📁 Proje Yapısı

lib/
├── models/ # Veri modelleri
├── widgets/ # Arayüz bileşenleri
├── expenses.dart # Gider ekranı
├── firebase_options.dart # Firebase yapılandırması
└── main.dart # Uygulama başlangıç noktası
